# Лабораторна робота №2. Консольні утиліти для задач кібербезпеки

**Варіант 11:** Аудитор ARP-таблиць та виявлення ARP-Spoofing

## Встановлення залежностей

Усі команди виконуються з кореня репозиторію. Потрібен Python 3.12 або новіший (перевірено на 3.14).

```bash
source venv/bin/activate
pip install -r requirements.txt
```

Залежності: лише стандартна бібліотека Python та `ruff` (лінтер і форматер).

## Структура файлів

Структура лабораторної роботи в репозиторії:

```
labs/lab02/
├── __init__.py
├── main.py                        # команди demo та analyze
├── task1.py                       # Завдання 1: User, Admin, Session, AuditLog, UserAccount
├── task2.py                       # Завдання 2: аудитор ARP-таблиць
├── README.md
├── _manifest.json
└── data/
    ├── arp_table.csv              # вхідна ARP-таблиця
    ├── arp_security_alerts.json   # JSON-звіт (створює утиліта)
    └── arp_audit.log              # журнал подій (створює утиліта)
```

## Приклади запуску

### Завдання 1: демонстрація ООП (`demo`)

```bash
python -m labs.lab02.main demo
```

### Завдання 2: аудит ARP-таблиці (`analyze`)

```bash
python -m labs.lab02.main analyze \
    --arp-file labs/lab02/data/arp_table.csv \
    --detect-spoofing \
    --output-json labs/lab02/data/arp_security_alerts.json \
    --log-file labs/lab02/data/arp_audit.log
```

Мінімальний запуск (лише валідація, без пошуку spoofing і без файлів):

```bash
python -m labs.lab02.main analyze --arp-file labs/lab02/data/arp_table.csv
```

## Вхідні дані

Файл `labs/lab02/data/arp_table.csv` має колонки `IP Address`, `MAC Address`, `Interface`, `Type`.
Утиліта приймає CSV (поля через кому) або текстовий файл, де поля розділені пробілами.
Рядок-заголовок пропускається автоматично.

## Параметри командного рядка

Команда `analyze`:

| Параметр | Опис |
|---|---|
| `--arp-file` | Обов'язковий. Шлях до файлу ARP-таблиці. |
| `--output-json` | Шлях до JSON-звіту. Якщо не вказано, звіт не зберігається. |
| `--detect-spoofing` | Прапорець. Вмикає пошук MAC-адрес, пов'язаних із кількома IP. |
| `--log-file` | Шлях до файлу журналу. Якщо не вказано, журнал виводиться лише в консоль. |

Команда `demo` параметрів не має.

## Поведінка при помилках

| Ситуація | Поведінка |
|---|---|
| Файл ARP-таблиці не знайдено або він недоступний | `ERROR` у журналі, код завершення `1`, без traceback. |
| Некоректний IP або MAC у рядку | `WARNING`, рядок пропускається та рахується як `Invalid Syntax`. |
| Не вдалося записати JSON-звіт | `ERROR` у журналі, код завершення `1`. |
| Виявлено spoofing | `CRITICAL` у журналі та блок `[ALERT]` у консолі, код завершення `0`. |
| Не вказано команду або `--arp-file` | Повідомлення `argparse`, код завершення `2`. |

MAC у форматі `0011.2233.4455` (з крапками, формат Cisco) не відповідає шаблону з шести пар, тому вважається некоректним.
