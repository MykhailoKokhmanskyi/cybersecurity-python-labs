# Лабораторна робота №3: Веб-API для обліку завантаження каналів зв'язку (Варіант 11)

Даний проєкт є реалізацією RESTful Web API для підсистеми обліку вимірювань завантаження каналів зв'язку без використання високорівневих ORM (з прямим використанням бібліотеки `sqlite3` та параметризованих запитів).

## 🚀 Основні можливості

- **База даних**: Таблиці `categories` (типи каналів) та `records` (вимірювання завантаження).
- **Валідація даних**: Автоматична валідація вхідних JSON-запитів за допомогою **Pydantic v2** (значення завантаження каналу в діапазоні `0.0` – `100.0` %).
- **Безпека**: Прямі SQL-запити з параметризацією (`?`) для запобігання SQL-ін'єкціям.
- **Фільтрація та Пагінація**: Фільтрація за категорією, статусом, мінімальним завантаженням та пошуком підрядка; підтримка параметрів `limit` і `offset`.
- **Транзакційність**: Атомарне масове додавання записів (`POST /records/bulk`) з автоматичним відкатом (`ROLLBACK`) у разі помилки чи конфлікту.
- **Документація**: Автоматична генерація OpenAPI / Swagger UI.

## 🛠 Інструкція з інсталяції та запуску

### 1. Створення та активація віртуального середовища

```bash
# З кореня репозиторію
python -m venv .venv

# Для Linux / macOS:
source .venv/bin/activate

# Для Windows (PowerShell):
.venv\Scripts\Activate.ps1
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 3. Ініціалізація та заповнення бази даних

Виконайте скрипт `seed.py` для створення таблиць бази даних `lab3.sqlite3` та заповнення їх початковими даними Варіанта 11 із файла `data/seed.json`:

```bash
python -m labs.lab03.seed
```

### 4. Запуск веб-сервера

Запустіть сервер розробки Uvicorn з кореневої директорії:

```bash
uvicorn labs.lab03.main:app --reload
```

Після запуску сервіс буде доступний за адресою: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## 🧪 Приклади основних запитів (cURL)

### 1. Перевірка статусу сервісу (Ping)
```bash
curl -X GET "http://127.0.0.1:8000/ping"
```

### 2. Отримання інформації про студента
```bash
curl -X GET "http://127.0.0.1:8000/student"
```

### 3. Отримання списку всіх категорій
```bash
curl -X GET "http://127.0.0.1:8000/categories"
```

### 4. Отримання записів з фільтрацією та пагінацією
Отримати вимірювання із категорією ID `1`, значенням завантаження не менше `70.0%`, обмежуючи результат 5 записами:
```bash
curl -X GET "http://127.0.0.1:8000/records?category_id=1&min_value=70.0&limit=5&offset=0"
```

### 5. Створення нового запису вимірювання
```bash
curl -X POST "http://127.0.0.1:8000/records" \
     -H "Content-Type: application/json" \
     -d '{
           "code": "NET-REC-009",
           "title": "Вимірювання каналу Одеса-Київ",
           "value": 75.5,
           "status": "new",
           "category_id": 1
         }'
```

### 6. Масове створення записів (Пакетна операція з транзакцією)
```bash
curl -X POST "http://127.0.0.1:8000/records/bulk" \
     -H "Content-Type: application/json" \
     -d '[
           {
             "code": "NET-REC-010",
             "title": "Вимірювання резервного каналу #1",
             "value": 45.0,
             "status": "new",
             "category_id": 3
           },
           {
             "code": "NET-REC-011",
             "title": "Вимірювання резервного каналу #2",
             "value": 88.2,
             "status": "new",
             "category_id": 3
           }
         ]'
```
